# 完成结果与查看状态

侧栏顺序为「进行中 → 已完成·待查看 → 项目分类」。顶部两组是跨项目快捷入口，保留会话原项目归属。

- 本轮成功完成后进入待查看；仍有后台任务时继续显示在进行中。
- 前台窗口获得焦点、没有应用弹窗或手机侧栏遮挡，且最新输出已加载并滚动到底部时，标为已查看。终端视图需连接正常且输出已经绘制。
- 已查看的完成会话显示为空闲，退出 Done，保留项目内的最近对话排序。失败、中断和等待输入保留真实状态。
- 批量归档空闲会话排除未查看完成结果；用户仍可手动归档单个会话。
- 宿主持久化 `completedAt` 和 `completionEventSeq`；重复完成通知和修改设置不生成新的完成标识。终端 Stop 在记录完成前同步最终对话。
- 查看记录按宿主和会话保存在当前浏览器/桌面存储中，同一存储范围内的窗口同步。不同设备不共享已读；存储不可用时仅在当前页面保留。
- 首次观察建立历史基线，已有完成会话不会全部变成未读；之后的新轮次即使在页面关闭期间完成，也可通过完成标识变化识别。旧版宿主未提供完成标识时保留普通项目列表展示。

验证覆盖首次基线、重复执行、刷新、过时确认、后台任务、多宿主隔离、窗口同步、存储不可用，以及终端最终输出与完成记录的顺序。
