# 终端上游请求重试提示

Claude Code 出现 `✻ Connection dropped (ECONNRESET) · retrying… · attempt 6/10` 时，终端屏幕解析器提取完整原文、当前次数和总次数，并通过会话 API 的 `live.retry` 返回。该信息来自当前屏幕，不写入历史执行状态。

会话仍属于运行中，保持停止按钮和进行中分类。前端在对话底部显示黄色提示及完整错误，在侧栏和会话标题显示「连接重试中 · 6/10」，状态详情可查看原文。此状态表示 CLI 正在重试上游请求，与浏览器到宿主的终端连接状态分别显示。

恢复正常活动、完成或等待用户输入后移除重试提示。次数达到 `10/10` 仍表示正在进行最后一次重试，不据此推断失败。没有次数时只展示重试及原文。

识别支持彩色输出、局部刷新、窄终端换行、Unicode/ASCII 省略号及倒计时形式。仅识别当前活动标记后的重试提示，普通对话中的错误文本不会自动改变状态。

验证包含屏幕解析、实际伪终端到会话列表 API 的重试/更新/恢复/完成流程，以及前端对话提示的渲染。
