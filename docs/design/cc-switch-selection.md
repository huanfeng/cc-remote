# CC-Switch 直接读取与会话选择

本轮收敛计划：废弃独立 cc-tool 工作流，仅保留 cc-remote 宿主。

1. 直接只读打开 CC-Switch SQLite，只投影供应商所需字段；不迁移、不写源库，不因额外列或版本号不同而拒绝。默认 ~/.cc-switch/cc-switch.db，可用宿主参数或环境变量指定。
2. 每次打开选择器读取最新目录，返回名称、ID、引擎、可用性说明；凭据不返回浏览器。Claude 公共连接设置合并后取白名单，Codex 取 TOML 连接/模型字段，拒绝不支持的认证形式并显示原因。
3. 新建使用 CC-Switch 当前供应商或显式原生配置；恢复默认保持原选择，支持改选。恢复会话身份与历史不改变，活动会话改选必须走现有中断确认入口。
4. 保留已有会话私有快照以兼容之前创建的会话；停止读取 cc-tool 的 profiles.json。ccr 与 Web 恢复对话框都接入选择。
5. 先补只读/Schema 扩展/公共配置/恢复选择回归测试，再实现；验证 Go 全量测试与 vet、前端测试和构建，并重新生成独立 cc-remote Windows/Linux 二进制。只在隔离数据上进行界面验证。

cc-tool 源码和既有数据保留为历史记录，README 标明废弃，不继续维护安装导入流程。
