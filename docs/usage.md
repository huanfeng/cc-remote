# 使用说明

本文是 [README](../README.md) 的详细补充。配置项见 [configuration.md](configuration.md)，工作原理与限制见 [architecture.md](architecture.md)。

## 两种会话

| | 终端会话 | 托管会话 |
| --- | --- | --- |
| 启动方式 | 在项目目录运行 `ccr`，或网页「新建」（默认即终端会话） | 网页「新建」选「托管会话」 |
| 进程 | 宿主持有一个交互式 Claude Code，本地终端随时接入 | 每轮一个 `claude -p` 子进程，用 `--resume` 恢复上下文 |
| 终端 | 原生终端界面，终端和网页都能发消息；关闭终端不会停止它 | 无终端，全部在网页操作 |
| 停止生成 | 终端 Esc，或网页「停止」 / Esc 键 | 网页「停止」 / Esc 键 |
| 模型 / 权限修改 | 终端 `/model`、`/effort`、Shift+Tab，或网页标签 | 网页会话设置，下一轮生效 |
| 用量统计 | 状态栏数据（模型、上下文、费用） | 有费用、tokens、耗时 |

### 用 ccr 启动

`ccr` 的用法和 `claude` 一样，只是 Claude Code 由宿主运行：

```sh
ccr                                   # 选择当前目录的终端会话接入，没有就新建
ccr --model sonnet --add-dir ../lib   # 带 Claude Code 参数新建终端会话
ccr "修复登录页"                       # 只有提示词时是「接入指定会话」；新建并发送请写 ccr -- "修复登录页"
ccr --resume <会话 ID>                # 以终端会话继续 Claude Code 会话（Claude Code 退出时提示的命令，把 claude 换成 ccr）
ccr -c                                # 继续当前目录最近的会话
cc-remote --data-dir /path/to/data -- claude --add-dir ../lib   # 同 ccr --，使用非默认数据目录
```

- 当前目录已有终端会话时，`ccr` 列出它们（状态、已接入的终端数、最近活动）让你选择：回车选最近一个没有终端接入的会话，都有终端接入时回车新建，`0` 新建。
- 接入一个已有终端接入的会话前会先确认：两个终端画面同步，输入会进入同一个 Claude Code。
- 带了 Claude Code 参数（或用了 `--`）时总是新建会话，剩下的文字作为第一条消息发送；参数随会话保存，宿主重启后恢复时照样带上。
- `--model`、`--effort`、`--permission-mode` 成为会话设置，可以在网页修改；宿主自己设置的参数（`--settings`、`--session-id`、`-p`、`--output-format` 等）会被拒绝。
- 宿主运行它自己配置的 Claude Code，`cc-remote -- claude` 里的 `claude` 只是占位。
- 旧的共享终端（Claude Code 在你的终端里运行、网页经 Channels 接入）已移除；之前的共享会话已自动转为终端会话，下次发送消息或用 `ccr` 接入时恢复原来的上下文。

### 托管会话

1. 登录网页，点击「新建」，输入名称和**宿主上已存在的绝对目录路径**，可选模型、推理强度、权限模式。
2. 发送任务；执行期间可以切到其它会话，会话之间可以并行。执行中可以继续发送消息（按钮显示「排队」，最多 5 条），由 Claude 排队，并在下一轮合并处理；多个设备同时发送也会按顺序送达。「停止」只中断当前一轮，排队的消息会继续；再按一次停止会结束进程。
3. Claude 请求审批或提问时，在会话中的操作卡片里回答。「允许」只同意本次请求；待回答的请求最多等待约 30 分钟。
4. 下一条消息自动用原 Claude 会话 ID 恢复上下文。
5. 刷新页面或关闭浏览器不会停止任务，消息保存在宿主的 SQLite 中。
6. Claude 调用子 agent 时，对话里显示一张子 agent 卡片：类型、任务描述、状态、工具次数、tokens 和耗时，运行中显示当前进度。展开后可以看到任务说明、子 agent 自己的消息和工具调用，以及最终结果。后台 agent 运行时会话本身可以继续使用，卡片和顶栏的任务按钮会显示「运行中」；点任务按钮打开「子 agent 与后台任务」面板，选择一项会跳转到对应的卡片或命令。

### 终端会话

宿主在伪终端（Windows 为 ConPTY）里持有一个交互式 Claude Code。网页和本地终端都可以接入同一个进程，切换前端时进程不会重启，子 agent、后台任务等长时间运行的工作也不会中断。设计说明见 [design/terminal-sessions.md](design/terminal-sessions.md)。

1. 网页「新建」，选「终端会话」，填写目录并勾选「信任此目录」（等同于在终端里确认信任此文件夹）。
2. 对话来自 Claude Code 的记录，消息以粘贴的形式送进终端。Claude 正在工作时发送的消息会显示「排队」。Claude 弹出权限框或提问框时，网页消息会先等待，等对话框关闭后再发送，以免误答对话框。AskUserQuestion 和计划确认可以在网页回答。「停止」相当于按 Esc，15 秒内再按一次相当于 Ctrl+C。
3. 点击会话标题栏的终端图标，复制接入命令，在宿主上运行即可在本地终端中操作同一个 Claude Code：

   ```sh
   ccr                       # 选择当前目录的终端会话接入，没有就新建（宿主未运行时自动在后台启动）
   ccr ls                    # 最近的终端会话（按活动时间，最多 20 个），选择编号接入，0 为新建
   ccr <会话 ID 前缀或标题>
   ccr --new --title 修复登录 --model sonnet
   ccr --resume <会话 ID>    # 以终端会话继续 Claude Code 会话：ID、ID 前缀或标题关键词；不带值则从当前目录的会话中选择
   ccr -c                    # 继续当前目录最近的 Claude Code 会话（同 claude --continue）
   cc-remote attach --host http://127.0.0.1:8787 <会话>   # 缩写 cc-remote a
   ```

   Claude Code 退出时提示的 `claude --resume <会话 ID>`，把 `claude` 换成 `ccr` 即可：宿主在该会话原来的目录里用 `--resume` 启动它，已经有对应终端会话时直接接入。不要让同一个会话同时在别的终端里运行。网页「终端历史」里的会话也可以「以终端会话继续」。

   按 `Ctrl+]` 断开，Claude Code 继续运行。多个前端可以同时接入，终端尺寸以最近一次调整的前端为准。Windows 的 ConPTY 只发送变化的字符，终端偶尔会留下没刷新的字符：每轮回复结束时会自动整屏重画，也可以按 `Ctrl+L`。
6. 网页标题栏显示 Claude Code 状态栏数据：模型、推理强度、上下文用量、时长和费用；Claude 工作时显示和终端相同的状态行（如 `Composing… (8m 33s · ↓ 26.2k tokens)`）。终端里的状态栏仍是你自己配置的那个。
7. 点模型或推理强度标签直接弹出列表切换（托管会话同样可用，作用于下一轮）。终端会话里相当于执行 `/model`、`/effort`：切换模型会让当前对话的提示缓存失效，网页会先提示，确认后由宿主替你确认 Claude Code 的「Switch model?」。注意 Claude Code 会把 `/model` 选择的模型保存为新会话的默认值（写入 `~/.claude/settings.json`），和在终端里执行一样。输入框左下角的 `/` 按钮打开命令列表。
8. 一轮结束后 Claude Code 在输入框里给出的下一步建议（灰色文字）显示在网页输入框上方：点击直接发送，「编辑」填入输入框。
9. Claude Code 的 recap（离开一段时间后它写下的「你离开期间」回顾）显示在对话里，终端历史同样显示。终端会话里，宿主在没有终端接入、网页也没有打开这个会话时告诉 Claude Code「失去焦点」，回来时恢复，所以 recap 和在本地终端里一样会出现（是否生成由 Claude Code 决定，可在 /config 关闭）。
4. 进程默认一直保留。宿主重启（包括 `cc-remote update` 升级）时，停止前正在运行的终端会话会在宿主恢复后自动用 `--resume` 重新启动；接入中的 `ccr` 不会退出，显示「宿主正在重启」，等宿主恢复（最多 3 分钟）后自动重新接入。Claude Code 自己退出的会话，下次发消息或接入时同样用 `--resume` 恢复上下文，提示缓存仍然有效。还没发过消息的会话会以全新会话启动。
5. 在终端里执行 `/clear` 或 `/resume` 时，网页会跟随新的 Claude 会话 ID。如果切换到的 Claude 会话已被另一个网页会话占用，网页不会跟随。

### 终端历史与导入

侧栏「终端历史」读取 Claude Code 本地的项目级 JSONL 记录（只读，不修改原文件）。可以「导入为托管会话」继续，导入前必须停止原终端进程；导入沿用原会话标题。

## 界面

- **会话列表**：桌面为左侧栏，手机为抽屉菜单，内容一致。显示执行中、等待操作、已完成、失败及终端会话是否在运行；后台会话持续刷新。打开过的会话标记「已缓存」，切换时保留消息、草稿、附件、滚动位置、工具展开状态和未提交的回答；点「×」释放缓存（会清除该会话的未发送草稿，宿主任务继续执行）。
- **侧栏**：可折叠；桌面端拖动右边缘调宽（200–480px，不超过窗口 40%，双击恢复默认，方向键每次 16px，宽度记在本机）。顶部显示宿主版本、Claude Code 连接状态和退出按钮；底部是「设置」和「服务状态」。
- **顶栏**：当前会话标题、项目目录，以及模型 · 推理强度 · 权限模式标签（继承值显示为「默认(…)」，`bypassPermissions` 标红，`dontAsk`/`auto` 标黄）、状态、刷新和「会话设置」。
- **输入**：Enter 或 Ctrl+Enter 发送（可选，会记住），Shift+Enter 换行，兼容中文输入法。
- **登录**：令牌保存在当前站点的 localStorage，刷新和重新打开无需重登；「退出」清除。

### 会话设置

点顶栏标签或齿轮打开。可修改模型、推理强度、权限模式（保存 / 取消 / 全部恢复默认），并显示会话 ID、Claude 会话 ID、目录、模式、创建时间和用量摘要。危险区提供「删除…」。

### 全局设置

侧栏底部「设置」分两部分：

- **CC Remote 默认**：新会话和 `ccr` 使用的默认模型、推理强度、权限模式。
- **Claude 用户配置**：可选直接写入 `~/.claude/settings.json`，会影响该账户下所有 Claude Code 使用。

生效顺序与写入细节见 [configuration.md](configuration.md#权限模式模型与推理强度)。

### 界面语言

网页和命令行支持简体中文和英文，默认跟随宿主的语言设置（安装时的 `--lang`，未设置时跟随系统）。网页可以在设置里为当前浏览器单独选择语言，不影响其它设备；命令行可用 `cc-remote service config --lang zh|en|auto` 修改服务的语言，或用环境变量 `CC_REMOTE_LANG` 临时指定。详见 [configuration.md](configuration.md#界面语言)。

### 模型选择器

设置、新建会话和会话设置共用同一个模型选择器，可以输入任意模型 ID，也可以从列表选择。列表来自 Claude Code 官方别名、settings 中的 `model`/`availableModels`/模型类环境变量、本机会话最近使用的模型，以及配置了 API 密钥时的 `/v1/models`；缓存 10 分钟，可手动刷新。

### 删除会话

侧栏会话项的删除图标（桌面悬停显示，手机常显）或会话设置中的「删除…」。确认后删除 CC Remote 中该会话的消息、审批记录、终端记录同步标记和上传的附件；**不会**删除 `~/.claude` 下的原生 JSONL，仍可在「终端历史」中查看或恢复。执行中的托管会话需勾选「先停止再删除」；运行中的终端会话删除时会结束其 Claude Code。

### 服务状态

侧栏底部「服务状态」每 5 秒刷新：版本、PID、运行时长、监听地址（非本机地址标注「局域网可访问」）、服务托管方式、Claude 版本、会话与待审批数量、数据库/附件/日志占用、累计轮次/费用/tokens、近 14 天（UTC）轮次与费用图表、可排序的会话统计表（点击行打开会话），以及日志末尾 80 行（访问令牌和 Bearer 凭证自动隐去）。

轮次按用户消息计算；费用、tokens 和耗时来自托管会话的 Claude 结果事件，终端会话显示为「—」。

## 网页命令

在输入框输入：

| 命令 | 作用 |
| --- | --- |
| `/help` | 列出可用命令 |
| `/status` | 当前会话与宿主状态 |
| `/config`、`/permissions` | 查看配置与权限设置 |
| `/model [名称]` | 不带参数列出可用模型；带参数设置当前托管会话的模型。加 `--default` 改 CC Remote 默认，`inherit` 恢复默认 |
| `/effort [级别]` | 同上，针对推理强度 |
| `/permission-mode [模式]` | 同上，针对权限模式 |
| `/clear`、`/new`、`/reset` | （托管会话）开始新的 Claude 上下文，保留历史显示 |
| `/stop` | （托管会话）停止当前轮次 |
| `/compact [保留重点]` | （托管会话）压缩上下文，对话中显示压缩前后的 token 数 |

### Claude Code 原生命令（托管会话）

托管会话中，Claude Code 支持的其它命令都会原样交给 Claude 执行，包括内置命令（如 `/context`、`/usage`、`/init`、`/recap`）、插件命令和技能，hooks、frontmatter 等原生机制照常生效。输入 `/` 时的命令菜单就是 Claude 上一轮启动时报告的命令列表；Claude 不支持的命令会直接提示，不会消耗一轮对话。`/resume` 等只能在终端交互界面使用的命令不在列表中。


## 附件

- 点击「＋ 附件」、粘贴或拖放到输入框；任意类型文件，单个最多 20 MiB，每条消息最多 8 个。
- PNG / JPEG / GIF 会校验内容（最多 2500 万像素）并显示缩略图；其它文件显示为文件卡片（名称、大小，可下载）。
- 文件保存在宿主数据目录 `uploads/<会话 ID>/`，文件名会清理（去掉路径和控制字符，最长 120 字节，保留扩展名）。
- 消息中会附上每个附件在宿主上的绝对路径和原文件名，提示 Claude 用 Read 工具读取（支持文本、PDF、图片、Notebook）；托管与终端会话相同，可能需要一次读取审批。
- 移除未发送的附件只是取消附加，文件仍留在宿主；删除会话时一并删除。目前没有其它自动清理。

## 查看文件

- Claude 消息里提到的文件路径（如 `docs/design/x.md`、`/home/me/app/main.go:12`、`C:\app\shot.png`）显示为链接，点开在查看器里查看；代码块和工具卡片的输出（如构建命令打印的产物路径）里的路径也一样。Read / Edit / Write 工具卡片展开后有「打开文件」按钮。
- Markdown 按格式渲染，可切换查看源码；其中的相对链接打开另一个文件（可返回），相对路径的图片直接显示。代码文件按语言高亮、显示行号，`:行号` 会标出并滚动到该行。PNG、JPEG、GIF、WebP、SVG 等图片直接预览；PDF 和其它无法预览的文件可以下载。文档里的 `#标题` 链接滚动到对应标题。
- 相对路径依次在文档所在目录、同一条消息（或文档、打开文档的那条消息）里出现的绝对目录、会话工作目录中查找。例如消息里写了 worktree 目录，其后的 `docs/...` 就在该 worktree 中查找。
- 只能打开会话工作目录，以及会话中出现过的目录、出现过的文件所在目录里的文件（符号链接按实际位置判断）；根目录、一级目录和用户主目录本身不会因为被提到而开放。超过 20 MiB 的文件不预览，但可以下载（不限大小，由浏览器直接下载，支持断点续传）；超过 2 MiB 的文本按纯文本显示，约 40 万字符以上的代码不高亮。网络共享路径（`\\host\share`）不会打开，以免宿主连接到其它机器。
- 终端历史（未导入的原生会话）不支持打开文件。

## 刷新与状态恢复

- 地址栏 hash 记录当前会话：托管 / 终端会话为 `#/s/<会话 ID>`，终端历史为 `#/native/<ID>`，欢迎页为空。可以收藏，浏览器前进 / 后退可在会话间切换。打开已删除或不存在的会话会回到欢迎页并提示「会话不存在或已删除」。
- 刷新后自动恢复：已打开的会话列表与当前会话、侧栏标签、每个会话未发送的输入、已上传未发送的附件、提问 / 计划 / 审批卡片里未提交的选择。保存在本浏览器 localStorage 的 `cc-ui:v1` 中，7 天未改动的草稿过期，总量约 1 MiB（超出时先丢最旧的）。
- 滚动位置（在底部时保持贴底）和工具展开状态只保存在当前标签页的 sessionStorage，关闭标签页即清除。
- 释放缓存或删除会话会清除该会话的本地草稿；退出登录清除全部 `cc-ui*` 数据。多个标签页同时编辑同一草稿时以最后写入为准。

## PWA

网页提供 PWA manifest 和静态资源缓存，可「添加到主屏幕」。PWA 安装与 Service Worker 通常要求 HTTPS（localhost 除外），通过局域网 HTTP 访问时界面可用，但可能无法安装。对话数据和 API 不进入离线缓存，不支持离线发送。
