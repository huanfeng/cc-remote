# 使用说明

本文是 [README](../README.md) 的详细补充。配置项见 [configuration.md](configuration.md)，工作原理与限制见 [architecture.md](architecture.md)。

## 两种会话

| | 共享终端会话 | 托管会话 |
| --- | --- | --- |
| 启动方式 | 在项目目录运行 `ccr`（或 `cc-remote -- claude`） | 网页「新建」 |
| 进程 | 一个长期运行的原生交互式 Claude Code | 每轮一个 `claude -p` 子进程，用 `--resume` 恢复上下文 |
| 终端 | 保留原生终端界面，终端和网页都能发消息 | 无终端，全部在网页操作 |
| 停止生成 | 只能在终端 | 网页「停止」 |
| 模型 / 权限修改 | 在终端用 `/model`、`/effort`、Shift+Tab | 网页会话设置，下一轮生效 |
| 用量统计 | 原生记录不含用量，显示「—」 | 有费用、tokens、耗时 |

### 共享终端会话

1. 确保宿主在运行（安装了服务即自动运行；未运行时 `ccr` 会自动在后台启动一个本机宿主）。
2. 在项目目录执行 `ccr`。它启动原生 Claude Code，并为该进程加载 CC Remote 的 Channels 桥接组件。
3. 首次运行时，在终端确认加载开发 Channel 和项目信任。该参数只允许加载指定的开发 Channel，不会跳过工具权限。
4. 会话自动出现在网页「会话」列表中，显示在线/离线状态，沿用原会话标题。终端和网页都可以发消息，两端共用同一个进程和上下文；网页退出不会停止终端。
5. 工具审批、AskUserQuestion 提问和计划确认可以在终端或网页回答，先到达的有效结果生效，另一端自动撤下。网页卡片上的「交给终端」会撤回网页提问，只在终端作答。

常用形式：

```sh
ccr                                   # 新会话
ccr --model sonnet                    # 参数原样传给 claude
ccr --resume <Claude 会话 UUID>       # 继续已有会话，标题自动读取
cc-remote --data-dir /path/to/data -- claude   # 使用非默认数据目录
```

- 网页「连接终端」对话框提供带当前宿主路径的完整命令，可直接复制。
- 已有会话首次启用桥接时，需要先退出原来的 Claude Code 进程，再用 `--resume` 恢复一次；之后在终端和手机间切换无需退出或导入。不要同时启动两个相同 ID 的原生进程。
- 正在运行但没有通过 `ccr` 启动的普通会话只能在「终端历史」里查看。
- 在终端执行 `/resume` 或 `/clear` 改变会话 ID 时，旧的网页绑定会自动断开，避免向错误的会话投递；需要时用目标会话的连接命令重新连接。同一数据目录中，一个共享会话只允许一个终端启动器。
- 多个终端各自注册，分别出现在会话列表。
- 旧的 `cc-remote terminal` 子命令继续可用（支持 `--host`、`--data-dir`、`--claude`、`--claude-config-dir`、`--resume`）。

参数透传规则（`--permission-mode`、`--model` 等默认值的追加，以及不支持的参数）见 [configuration.md](configuration.md#ccr-与共享终端参数)。

### 托管会话

1. 登录网页，点击「新建」，输入名称和**宿主上已存在的绝对目录路径**，可选模型、推理强度、权限模式。
2. 发送任务；执行期间可以切到其它会话，会话之间可以并行。执行中可以继续发送消息（按钮显示「排队」，最多 5 条），由 Claude 排队，并在下一轮合并处理；多个设备同时发送也会按顺序送达。「停止」只中断当前一轮，排队的消息会继续；再按一次停止会结束进程。
3. Claude 请求审批或提问时，在会话中的操作卡片里回答。「允许」只同意本次请求；待回答的请求最多等待约 30 分钟。
4. 下一条消息自动用原 Claude 会话 ID 恢复上下文。
5. 刷新页面或关闭浏览器不会停止任务，消息保存在宿主的 SQLite 中。

### 终端历史与导入

侧栏「终端历史」读取 Claude Code 本地的项目级 JSONL 记录（只读，不修改原文件）。可以「导入为托管会话」继续，导入前必须停止原终端进程；导入沿用原会话标题。

## 界面

- **会话列表**：桌面为左侧栏，手机为抽屉菜单，内容一致。显示执行中、等待操作、已完成、失败及共享终端在线/离线状态；后台会话持续刷新。打开过的会话标记「已缓存」，切换时保留消息、草稿、附件、滚动位置、工具展开状态和未提交的回答；点「×」释放缓存（会清除该会话的未发送草稿，宿主任务继续执行）。
- **侧栏**：可折叠；桌面端拖动右边缘调宽（200–480px，不超过窗口 40%，双击恢复默认，方向键每次 16px，宽度记在本机）。顶部显示宿主版本、Claude Code 连接状态和退出按钮；底部是「设置」和「服务状态」。
- **顶栏**：当前会话标题、项目目录，以及模型 · 推理强度 · 权限模式标签（继承值显示为「默认(…)」，`bypassPermissions` 标红，`dontAsk`/`auto` 标黄）、状态、刷新和「会话设置」。
- **输入**：Enter 或 Ctrl+Enter 发送（可选，会记住），Shift+Enter 换行，兼容中文输入法。
- **登录**：令牌保存在当前站点的 localStorage，刷新和重新打开无需重登；「退出」清除。

### 会话设置

点顶栏标签或齿轮打开。可修改模型、推理强度、权限模式（保存 / 取消 / 全部恢复默认），并显示会话 ID、Claude 会话 ID、目录、模式、创建时间和用量摘要。共享终端会话为只读。危险区提供「删除…」。

### 全局设置

侧栏底部「设置」分两部分：

- **CC Remote 默认**：新会话和 `ccr` 使用的默认模型、推理强度、权限模式。
- **Claude 用户配置**：可选直接写入 `~/.claude/settings.json`，会影响该账户下所有 Claude Code 使用。

生效顺序与写入细节见 [configuration.md](configuration.md#权限模式模型与推理强度)。

### 模型选择器

设置、新建会话和会话设置共用同一个模型选择器，可以输入任意模型 ID，也可以从列表选择。列表来自 Claude Code 官方别名、settings 中的 `model`/`availableModels`/模型类环境变量、本机会话最近使用的模型，以及配置了 API 密钥时的 `/v1/models`；缓存 10 分钟，可手动刷新。

### 删除会话

侧栏会话项的删除图标（桌面悬停显示，手机常显）或会话设置中的「删除…」。确认后删除 CC Remote 中该会话的消息、审批记录、共享终端同步记录和上传的附件；**不会**删除 `~/.claude` 下的原生 JSONL，仍可在「终端历史」中查看或恢复。执行中的托管会话需勾选「先停止再删除」；在线的共享终端须先退出终端。

### 服务状态

侧栏底部「服务状态」每 5 秒刷新：版本、PID、运行时长、监听地址（非本机地址标注「局域网可访问」）、服务托管方式、Claude 版本、会话与待审批数量、数据库/附件/日志占用、累计轮次/费用/tokens、近 14 天（UTC）轮次与费用图表、可排序的会话统计表（点击行打开会话），以及日志末尾 80 行（访问令牌和 Bearer 凭证自动隐去）。

轮次按用户消息计算；费用、tokens 和耗时来自托管会话的 Claude 结果事件，共享终端会话显示为「—」。

## 网页命令

在输入框输入：

| 命令 | 作用 |
| --- | --- |
| `/help` | 列出可用命令 |
| `/status` | 当前会话与宿主状态 |
| `/config`、`/permissions` | 查看配置与权限设置 |
| `/model [名称]` | 不带参数列出可用模型；带参数设置当前托管会话的模型。加 `--default` 改 CC Remote 默认，`inherit` 恢复默认 |
| `/effort [级别]` | 同上，针对推理强度 |
| `/permission-mode [模式]` | 同上，针对权限模式 |
| `/clear`、`/new`、`/reset` | （托管会话）开始新的 Claude 上下文，保留历史显示 |
| `/stop` | （托管会话）停止当前轮次 |
| `/compact [保留重点]` | （托管会话）压缩上下文，对话中显示压缩前后的 token 数；共享会话请在终端执行 |

### Claude Code 原生命令（托管会话）

托管会话中，Claude Code 支持的其它命令都会原样交给 Claude 执行，包括内置命令（如 `/context`、`/usage`、`/init`、`/recap`）、插件命令和技能，hooks、frontmatter 等原生机制照常生效。输入 `/` 时的命令菜单就是 Claude 上一轮启动时报告的命令列表；Claude 不支持的命令会直接提示，不会消耗一轮对话。`/resume` 等只能在终端交互界面使用的命令不在列表中。

### 共享会话

共享会话中，Claude 运行在你的终端里，网页消息通过 Channels 送达，Claude Code 不会把它当作命令执行。因此原生命令（含 `/compact`、`/clear`）需要在终端输入。网页仍可使用 `/help`、`/status`、`/config` 等网页命令，自定义命令和技能会展开为提示词发送（只支持静态 `$ARGUMENTS`）。

## 附件

- 点击「＋ 附件」、粘贴或拖放到输入框；任意类型文件，单个最多 20 MiB，每条消息最多 8 个。
- PNG / JPEG / GIF 会校验内容（最多 2500 万像素）并显示缩略图；其它文件显示为文件卡片（名称、大小，可下载）。
- 文件保存在宿主数据目录 `uploads/<会话 ID>/`，文件名会清理（去掉路径和控制字符，最长 120 字节，保留扩展名）。
- 消息中会附上每个附件在宿主上的绝对路径和原文件名，提示 Claude 用 Read 工具读取（支持文本、PDF、图片、Notebook）；托管与共享会话相同，可能需要一次读取审批。
- 移除未发送的附件只是取消附加，文件仍留在宿主；删除会话时一并删除。目前没有其它自动清理。

## 刷新与状态恢复

- 地址栏 hash 记录当前会话：托管 / 共享会话为 `#/s/<会话 ID>`，终端历史为 `#/native/<ID>`，欢迎页为空。可以收藏，浏览器前进 / 后退可在会话间切换。打开已删除或不存在的会话会回到欢迎页并提示「会话不存在或已删除」。
- 刷新后自动恢复：已打开的会话列表与当前会话、侧栏标签、每个会话未发送的输入、已上传未发送的附件、提问 / 计划 / 审批卡片里未提交的选择。保存在本浏览器 localStorage 的 `cc-ui:v1` 中，7 天未改动的草稿过期，总量约 1 MiB（超出时先丢最旧的）。
- 滚动位置（在底部时保持贴底）和工具展开状态只保存在当前标签页的 sessionStorage，关闭标签页即清除。
- 释放缓存或删除会话会清除该会话的本地草稿；退出登录清除全部 `cc-ui*` 数据。多个标签页同时编辑同一草稿时以最后写入为准。

## PWA

网页提供 PWA manifest 和静态资源缓存，可「添加到主屏幕」。PWA 安装与 Service Worker 通常要求 HTTPS（localhost 除外），通过局域网 HTTP 访问时界面可用，但可能无法安装。对话数据和 API 不进入离线缓存，不支持离线发送。
