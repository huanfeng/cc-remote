# CC-Switch 供应商配置调研与迁移边界

调研日期：2026-11-18。范围为 Claude Code / Codex 的直连配置与切换。

| 能力 | cc-remote 当前状态 | 后续建议 |
| --- | --- | --- |
| API Key / Bearer Token、端点、默认模型 | 已支持 | 保持凭据只写不回填 |
| Claude 模型映射、超时；Codex 思考/上下文参数 | 已支持常用项 | 增加子代理模型、重试和流超时等连接选项 |
| 模型自动获取、连接检测 | 已支持模型列表接口检测 | 后续可增加显式生成检测及费用提示 |
| 多端点与测速选择 | 单端点，提供列表请求耗时 | 增加手动多端点管理，不自动路由 |
| 供应商分组、图标、排序、预设库 | 有基础预设、备注、官网 | 增加分组、排序及更完整预设 |
| 通用供应商跨应用复用 | 每应用独立配置 | 后续支持共享来源、分别生成连接配置 |
| 配置 JSON / TOML | 供应商公开字段 JSON；Claude 原生安全 JSON | 增加受约束的高级连接字段编辑 |
| 导入和备份 | 已支持本机 CC-Switch API 连接逐项复制导入 | 后续增加加密备份及可审阅批量导入 |
| 官方订阅账号 | Claude OAuth 令牌；宿主原生登录 | 独立调研 Codex OAuth 账号管理 |
| 配额查询、供应商自定义脚本 | Claude 提供的用量信息 | 后续评估统一配额接口，不导入执行脚本 |
| 本地路由、聚合、协议转换、故障转移 | 不在当前范围 | 保持当前直连范围 |
| MCP、提示词、Skills、其它应用 | 不属于供应商迁移 | 不通过连接导入修改这些全局设置 |

## 本次导入行为

- 数据库以只读方式访问。选择“导入本地副本”后复制 API 凭据、端点、模型映射和支持的连接选项到宿主私有存储。凭据不经过浏览器回填。
- 相同应用和来源 ID 防止重复导入，后续 CC-Switch 的修改不会同步覆盖本地副本。
- 不能完整表达的连接参数拒绝导入并提示；全局工具配置、MCP、路由元数据、历史记录不纳入连接迁移。
- “显示 CC-Switch 供应商列表”关闭后，所有供应商选择列表停止读取 CC-Switch。已有默认供应商必须先导入或改选本地/原生配置，避免静默切到其它供应商。
- 已导入配置可独立修改、使用和删除。默认供应商映射保存后，即使原数据库不再存在，本地副本仍可使用。
